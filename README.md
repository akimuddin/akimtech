# AkimTech — Global Portfolio Website

A modern, responsive personal portfolio website for **Md Akim Uddin**, showcasing professional web design and development services.

## ✨ Features

- Fully responsive desktop, tablet, and mobile layout
- AkimTech personal branding
- Sticky responsive navigation with hamburger menu
- Scroll percentage progress bar
- Active menu highlighting with cyan `#00C3FF`
- Professional hero section with profile image
- About Me and core expertise sections
- Services showcase
- Filterable portfolio
- Portfolio filters for WordPress, Agency, WooCommerce, Landing Page, and Frontend
- WOW.js and Animate.css animations
- Call-to-action section
- Contact form
- Google Maps integration
- Font Awesome icons
- jQuery interactions
- Back-to-top button
- Responsive footer

## 🛠️ Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Font Awesome
- WOW.js
- Animate.css
- Google Maps Embed

## 🚀 Getting Started

No build process is required.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Then open `index.html` in your browser.

For development, you can use **VS Code Live Server**.

## 🌐 External Libraries

The project uses CDN-hosted libraries for Bootstrap, Font Awesome, jQuery, WOW.js, and Animate.css.

Google Maps is embedded through Google Maps.

An internet connection is required for these external resources.

## 📩 Contact Form

The contact form is currently front-end only.

Before deploying it as a production website, connect it to a backend or email service such as Formspree, EmailJS, PHP, or another preferred form-processing solution.

## 🎨 Customization

### Branding

Replace:

```text
assets/logo.png
```

with your preferred logo.

Replace:

```text
assets/akim-uddin.png
```

with your preferred profile image.

### Portfolio

Replace the portfolio demo visuals and descriptions with your actual project screenshots, project details, categories, and live project links.

### Contact Information

Update the contact section with your preferred professional email, phone, location, LinkedIn profile, and other links.
